# David Litescu — Portfolio

Personal portfolio built with Next.js 16, Tailwind CSS, and TypeScript.

## Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Fonts**: DM Serif Display + DM Sans (Google Fonts)
- **Animations**: Framer Motion
- **Deploy**: Vercel

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customization

- **Projects**: edit `app/data/projects.ts`
- **Translations**: edit `app/data/i18n.ts`
- **CV**: replace `public/cv.pdf`

## Deploy

Push to GitHub, then import on [vercel.com](https://vercel.com). Zero config needed.
