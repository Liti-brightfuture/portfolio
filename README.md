Outside work I've shipped 13 apps — Solana token intelligence dashboards, CRM platforms, grooming salon booking, transport fleet tracking, prediction market bots, automated video pipelines. Each one solving a real problem for real users.

I use AI to move faster. The actual work is knowing what to build, how to structure it, and writing prompts that produce real code.
